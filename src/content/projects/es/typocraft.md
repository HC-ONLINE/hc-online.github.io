## Qué resuelve

- Necesidad de un editor Markdown interactivo con preview en tiempo real.
- Transformar escritura Markdown en diferentes estilos tipográficos.
- Interfaz responsive para escritorio y tablet.

## Características clave

- Editor Markdown en vivo con preview en tiempo real.
- Múltiples temas tipográficos:
  - Manuscript (clásico, elegante)
  - Modernist (limpio, contemporáneo)
  - Deep Night (oscuro, sofisticado)
- Interfaz responsive para escritorio y tablet.
- Soporte completo de Markdown (encabezados, listas, código, blockquotes, etc.).
- Cambio de temas en tiempo real sin perder contenido.
- Sincronización bidireccional de edición.
- Sistema de temas extensible.

## Decisión técnica

- Combinar Astro con React para la interacción del editor.
- Usar Marked para el procesamiento Markdown en tiempo real.
- Priorizar la experiencia de usuario con preview instantáneo y cambio de temas fluido.
